## Community nodes in Boltjar

A custom node written by someone in the community can become part of Boltjar itself. That only happens with its author's agreement: the author opens a pull request with the node (or gives written permission to add it), it comes in under Boltjar's license, and the author is credited here, on the node's page in the docs and in the release notes.

## Contributors

Everyone whose pull request is merged is listed in the project's history on GitHub, with their own sign-off on every commit.
